# Brent Oil Price Change Point Analysis

## Project Overview

This project analyzes historical Brent crude oil prices to identify structural changes using Bayesian Change Point models.

## Objectives

- Understand Brent oil price behavior
- Investigate trends and volatility
- Link structural changes with geopolitical and economic events
- Produce insights for investors and policymakers
